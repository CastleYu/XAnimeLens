设置（API Key / Token）

两项都可留空；填写后识别更稳定。

  1. Bangumi Token（作品与角色信息查询，含 R18 条目；不填也能用）： 没有账号先 注册 Bangumi， 登录后打开 个人令牌页 →「创建个人令牌」→ 名称随意、有效期选最长 → 复制生成的令牌粘贴到上面，点「保存」。
  2. trace.moe API Key（提高每日识别额度，按最近 24 小时计）： 打开 trace.moe 账户页 按页面说明获取 Key（通常需赞助），复制到上面并保存。

令牌只保存在本机浏览器（chrome.storage.local），不会上传到其他地方。
